# Contributing

Thanks for wanting to help.

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Keep changes small and include tests (`npm test`) and a clean type check (`npm run typecheck`).
3. Contributions require signing the Contributor License Agreement (CLA) so Hody LLC (the CLA grantee) can grant license exceptions. You will be asked to sign it on your first pull request.

Do not put secrets, account ids or real hostnames in issues, code or tests. Use example hosts such as `dash.example.com`.
