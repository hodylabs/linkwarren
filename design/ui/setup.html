Connect Cloudflare

linkwarren runs in your own Cloudflare account. Give it an API token so it can attach your domains and issue certificates. The token is stored as a Worker secret and never shown again.

● 3 of 4 permissions

What the token can do

✓
Zone, Zone, ReadSee which domains are in this account
✓
Zone, DNS, EditPoint your domains at linkwarren
✓
Account, Workers Routes, EditSend each domain's traffic to the app
!
Zone, SSL and Certificates, EditAdd outside domains with a CNAME (Cloudflare for SaaS)
The token can't add outside domains yet. That's fine if every domain you'll use is in this Cloudflare account. To let people add their own domains with a CNAME, edit the token to include SSL and Certificates, then check again.
